## 制作原则

使用自己的字形骨架与角色构造；保留区分汉字的关键笔画。参考图只用于了解视觉方向，不提取其字形。原型由 Codex 辅助创建，后续必须记录人类设计师的独创修改、选择和定稿过程，不能直接据此声称每个字都享有排他性版权。

建议分阶段：24 个方向样字 → 100 个结构验证字 → 500 个试用字 → 3,500 常用汉字及配套字符 → 有需求再扩到 6,500 / 8,105 字及繁体。扩字须逐字设计与审校。

## 本地构建

```sh
uv venv .venv
uv pip install --python .venv/bin/python -r requirements.txt
.venv/bin/python scripts/build_v02.py
```

修改 `sources/design_v02.py` 中的坐标和笔画，再构建。坐标为 1,000 单位方格，y 向下；笔画扩展成闭合轮廓后合并。`sources/v02/uni*.json` 是构建导出记录，不是编辑入口。字体输出 TTF、WOFF2；PNG 样张的说明文字在 macOS 上使用系统黑体，**不包含在新字体中**。

当前 PNG 构建依赖 macOS 系统字体路径；字体构建本身使用 Python / fontTools / Shapely。当前轮廓采用折线近似，未做手工 hinting，正式发行前需曲线优化、小字号与跨平台检查。
