# 相似字体初步调研

检索日期：2026-09-28。范围：公开网页、字库产品介绍、字样图片及截图来源线索。不是穷尽式字体检索或法律清权结论。

## 结论

已有“把眼睛、笑脸融入文字”的字体与手写艺术，不能把这个概念当作本项目首创。尚未找到证据确认用户截图的具体字库名称、原作者或完整可安装字体。

## 对当前原型的影响

“圆角笔画+两个眼睛”本身差异不足。现有24字继续作为方向实验，不作“独创风格”宣传，也不直接扩为3500字后出售。下一步应把相同代表字并排比较，重点检查：脸部轮廓、眼睛位置、口/日/月部件规则、复杂字处理及阅读效果。发展自己的角色形态、部件系统和可选表情字形。

本次没有下载或安装第三方字体文件，没有取得商业许可，也没有对原型做侵权与否的法律判断。
