# 字体保护、申请与商业化

核查日期：2026-09-28。适用重点：中国大陆；澳大利亚仅作补充。以下是项目规划与一般信息，具体申请对象、权利归属和合同须按最终作品及申请人情况审查。

## 先回答“这属于哪种专利”

单纯把字体外形设计得活泼，通常不属于发明或实用新型的技术方案。若考虑专利，应评估**外观设计专利**这条路线，但不能从“是新字体”直接推导出“能够获得外观设计专利”。

中国专利法中的外观设计以产品整体或局部的形状、图案等为对象，要满足新颖性等要求；纯粹抽象的视觉风格不能被一份专利全部垄断。字体/字形以何种产品或载体申请、保护对象是否合格、是否涉及平面印刷品主要起标识作用的排除情形，须由代理师针对具体方案判断。没有找到足以确认本项目独立字库可以直接申请的官方依据，因此这里不作可专利性结论。

如经评估可申请：先检索现有设计与在先权利 → 明确申请人、设计人及产品对象 → 准备请求书、图片或照片、简要说明 → 经国家知识产权局专利业务办理系统提交 → 补正/审查、缴费、授权及年费维护。外观设计专利期限为申请日起 15 年；权利范围取决于获授权的具体设计。不要把整套 3,500 字当然视为一个可合案的设计。未得到申请策略意见前，本项目保持本地，避免自行公开影响新颖性；公开例外不能一概适用。

来源：[专利法，尤其第2、23、25、27、42条](https://www.cnipa.gov.cn/art/2020/11/23/art_97_155167.html)；[官方提交入口](https://cponline.cnipa.gov.cn/)。

## 本项目优先采用的保护组合

| 对象 | 保护路径 | 限制 |
|---|---|---|
| 具有独创性的具体字形、美术设计 | 著作权与作品自愿登记 | 不是每个汉字都自然达到独创性标准；登记不是法院对权利范围的最终认定 |
| 具有可保护内容的程序与文档 | 按实际内容评估软件著作权 | TTF 文件扩展名不等于符合软件登记要求；脚本的权利也不等于每个字形的权利 |
| 字体名称、品牌标志 | 商标检索与申请 | 商标保护标识与相关商品服务上的来源区分，不能垄断所有相似风格 |
| 客户的使用范围、交付和费用 | 清楚的授权合同/EULA | 合同约束相应当事人，不能凭合同创造对所有第三人的版权 |
| 符合条件的具体产品外观 | 外观设计专利评估 | 不是字体商业化的必需前置条件，地域与对象均有限制 |

最高法院介绍过“汉仪秀英体”相关案件：具有独创性的字库单字可受美术作品保护，但简单笔画字的独创空间有限。这说明“有字库=每个字均享有同等排他保护”并不成立。[最高人民法院案例报道](https://www.court.gov.cn/zixun/xiangqing/407142.html)

作品实行自愿登记，不登记不影响依法取得的著作权；登记有初步证据作用。建议将最终字形样本、创作说明、作者/权利人身份材料和权利归属文件整理后，向有受理权限的作品登记机构办理；软件登记另按程序与文档准备。申请人的国籍、主体类型和所在地可能影响受理安排，不能仅用澳洲工作电脑推断申请人身份。[国家版权局：作品自愿登记试行办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/P020241015603746503748.pdf)；[计算机软件著作权登记办法](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)

## 原图参考与 AI 辅助

截图来源尚未核实，视频账号不一定是书法作者；“稍作调整”不是法定免责标准，不存在统一的“改30%就不侵权”。本原型没有导入第三方字体、提取截图轮廓或逐字描摹，但这不是完成了相似性检索或获得商业清权的声明。

当前字形是 Codex 辅助设计、程序构建的候选方案。不要把这一轮自动产物直接包装成人类手绘作品，或保证拥有稳定的排他性著作权。后续应由人类设计师实质参与构形、表情、笔画、比例和修订，保存各版本、理由、草图与签署的归属约定；最终可保护性仍取决于具体事实。单纯保存提示词或 Git 记录也不能制造原本不存在的独创性。

法院资料强调人类对最终表达的独创性贡献。[最高法院知识产权法庭关于人类贡献的讨论](https://ipc.court.gov.cn/zh-cn/news/view-5662.html)。2026年9月最高法《意见》第十二条还明确涉及使用 AI 生成与已知在先作品实质相似内容的责任；使用 AI 不消除参考原作的风险。[官方意见](https://www.court.gov.cn/zixun/xiangqing/511101.html)

## 怎样赚到钱

卖“明确范围内的使用许可”和相关服务。客户付款后得到字体文件、许可文本、授权凭证和覆盖字表。通常按主体、用途、席位、项目、品牌、嵌入产品或期限定价；只有合同明确约定并有结算机制时，才可能按销售量/使用量收取版税。并非别人每打一个字就自动给你分钱。

| 产品 | 目标客户 | 核心界限 |
|---|---|---|
| 小范围试用字体 | 潜在买家 | 明确试用字数、期限和用途；“免费下载”不等于“免费商用” |
| 创作者商用授权 | 自媒体、设计师 | 账号、主体、席位；视频、海报、客户委托项目是否允许 |
| 企业品牌授权 | 品牌、门店、出版方 | 指定主体/品牌；包装、广告、印刷、logo是否包含 |
| 嵌入授权 | 网站、App、游戏、硬件 | 字体程序的分发、域名/产品数、用户规模、提取限制 |
| 定制字与定制字体 | 品牌、文创客户 | 新增字、独家范围、买断/许可、源文件交付另议 |
| 平台合作 | 字体或设计工具平台 | 先核实准入、抽成、独家期限、补字维护与退出条款 |

早期建议先验证短视频标题、手账、文创包装三种真实用途。先用100–500字展示效果、收集缺字与付费意愿；对客户明确有限覆盖，不当作完整中文字体销售。整套字库上线前可做少量品牌标题定制，但同样需要完成相应字形的权利审查。

暂不设“市场标准价”：销售量、价格和平台抽成均未验证。可通过访谈、授权范围对比、少量付费订单试验定价。优先证实买家需求，再决定是否投入上千小时扩字。

## 授权文件须写清

权利人与被许可主体；字体名称及版本；可用渠道和用途；期限与地域；席位或设备数；客户项目是否涵盖；广告/包装/logo等范围；嵌入、转授权、源文件转交及修改限制；订阅终止后已发布内容如何处理；缺字更新与支持；退款、违约和争议解决。

不要对当前样字签发“保证完全原创、绝不侵权”的承诺。首份正式合同应结合完成的权利清查和真实业务审核。

## 可执行的下一步

1. 确认24字样张的风格；人工修改并记录版本，制作100字结构样本。
2. 补充原视频链接、寻找原作者；开展相似字体和品牌名称检索。
3. 让设计师与中国知识产权专业人士检查代表字、创作记录、作者/委托关系，确定登记与专利是否值得做。
4. 保存定稿字形、字体文件校验值、创作说明和权利材料；办理适用的自愿登记、品牌商标等。
5. 选择一类授权做清晰的商品页面和许可文本；用户另行决定销售渠道与公开发布。

## 澳大利亚补充

澳大利亚一般著作权保护自动产生，没有通用的版权注册申请制度；patent、design right、trade mark 各自保护不同对象。不能把中国字体单字案件结论直接用于澳洲，也不能假设中国申请在澳洲自动生效。澳洲字体/软件保护及设计登记适用性应单独评估。[IP Australia 官方介绍](https://www.ipaustralia.gov.au/tools-and-research/business-resources/choosing-the-right-ip-tool)
