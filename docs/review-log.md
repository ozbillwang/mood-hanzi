# 评审与创作记录

## 2026-09-28 / v0.1

- 用户提出以视频截图为灵感创建新字体，确认中国大陆市场优先、汉字可读性优先并加入圆脸和表情。
- Codex 辅助创建24字坐标草稿：独立编写笔画路径，没有将截图或现成字体输入构建程序。
- 第一轮实际TTF样张发现水、火、人、小、光的眼睛靠近竖笔，装饰效果不理想；第二轮改为顶端椭圆圆脸，保留主要汉字骨架。其余框形增加圆角。
- 这份记录说明工具流程，不能证明人类已经逐字创作或取得全部排他权。人类设计师的实质修改、定稿与归属确认仍待进行。

## 已完成检查

- TTF 经 fontTools 重新打开；cmap 含24汉字、4标点及空格，含 .notdef 共30 glyph。
- 所有可见 glyph 轮廓在0–1000横向、-100–900纵向范围内。
- WOFF2重新读取后的Unicode映射与TTF一致。
- Pillow/FreeType直接加载TTF并输出样张；查看样张确认未出现缺字方框、裁切或重叠排版。
- 试字页对未收录字符显示系统字体并明确标记，避免将字体回退当作新字体覆盖。

## 下一轮要解决

- 24字以独体字为主，尚不能证明该风格适合复杂合体字；需100字结构样本验证。
- 表情大小与位置尚未最终统一；圆脸与非圆脸字的组合需要用户评审。
- 尚未进行独立读者盲读、Windows/设计软件兼容、浏览器交互验收或专业字体工具验证。
- 没有手工hinting；当前轮廓为多边形近似，正式发行前需优化曲线节点与小字号显示。
- 数字、英文字母、其余标点和3,500字覆盖均未完成。
- 原作者、原视频来源、相似字体、名称商标与可保护性尚未完成核查。

当前结论：可以作为方向讨论和本地安装测试的原型，不是可直接销售的完整字体。


## v0.2 · 2026-09-28

用户修正：更靠近参考截图，不能只靠圆脸。第二版将方向改成“整字拟人、偏旁互动、细线手写”，保留 v0.1 全部交付。

重新设计 24 个汉字，加入是、空、多、无、色、有、明、想、音、笑、呆、不等结构样本。多的两个夕变成斜向呼应的轮廓；是与呆的上部成为头、下部成为站姿；心采用张开的托举轮廓；明、想用偏旁的大小差产生互动。线宽由 46 改为 28 单位，表情笔画为 23 单位。绘制使用独立坐标，没有从截图追踪或提取轮廓。

当前仍有辨识性权衡：人/大等增加了封闭轮廓，无采用更强的帽形上部；需要用户评审和后续盲读测试。不能把本次样稿视作最终风格或完整字库。

验证：用实际生成 TTF 渲染新样张及同字前后对比；检查 TTF/WOFF2 字符映射、字形边界、字体名称和轮廓；重复构建比对二进制哈希。未进行操作系统安装或跨平台测试。
